en: Each host now has one default launch profile: choose it as the Default Shell when editing the host, or in the profile settings, or leave it on Automatic, the shell detected there. New terminals and Ctrl+Shift+1 start it, and the profile menu marks it. On Windows, Automatic is PowerShell 7 when it is installed, else Windows PowerShell.
