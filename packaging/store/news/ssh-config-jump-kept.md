en: A host from ~/.ssh/config whose ProxyJump names a saved host with another user or port keeps that jump, and Test Connection checks the jump the added host will use.
fr: Un hôte de ~/.ssh/config dont le ProxyJump nomme un hôte enregistré avec un autre utilisateur ou port garde ce saut, et Tester la connexion vérifie le saut qu’utilisera l’hôte ajouté.
